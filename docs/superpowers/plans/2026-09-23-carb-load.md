### Task 4 — app.js creation flow
- Add `<option value="carb_load">Pre-race carb load</option>` to type select in `renderCreate()`
- `_applyMultiDayToggle()` (or date-change handler): when `type === 'carb_load'` and dates are set, call new `_generateCarbLoadSegments(start, end)` helper
- `_generateCarbLoadSegments(start, end)`: enumerate calendar days, create one `Data.newSegment({ mode: 'daily', date: dayStr, name: 'Day N' })` per day; for single-day, one segment with `date` = event date
- `segmentFormHTML()`: when segment `mode === 'daily'`, show "Carbs/day (g)" / "Sodium/day (mg)" fields; hide Duration / Carbs/hr / Na/hr / Caffeine/hr; date field read-only

- `segmentSectionHTML(seg, multiSeg, actuals)`: add third param; when `seg.mode === 'daily'`:

  - Progress bar rate labels: "Ng/day", "Nmg/day"; `carbsPerHour` IS the daily value, display directly
  - Totals line: "Ng carbs · Nmg Na · Day N" (no duration)
  - Skip execution plan row

- Summary strip: if `evt.type === 'carb_load'`, card 3 = "TARGET" (sum of `seg.carbsPerHour` across days) instead of caffeine
